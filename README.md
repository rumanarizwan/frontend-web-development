# Frontend Web Development Project

A multi-page website built using semantic HTML5, CSS3, and JavaScript.

## 🛠️ Tech Stack
* HTML5
* CSS3
* JavaScript

## 📁 Project Structure
* `index.html` - Homepage
* `mens section.html`, `office wear.html` - Categorized web pages
* `css/` - Custom stylesheets
* `images/` - Media assets

## 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser.
